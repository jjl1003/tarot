# 月下手札 · 塔罗

支持本地运行和邀请码在线体验的 78 张经典韦特塔罗与 AI 解读工具。支持 78 张正逆位牌义手册、22 种牌灵档案、三种牌阵、实际洗切牌、手动选牌与翻牌、连续追问、一次补牌、本地历史和中断恢复。

## 牌义手册

首页“牌义手册”可独立查阅全部 78 张牌，无需配置模型或开启手札。支持中文／英文牌名、常见译名、正逆位关键词搜索，以及大阿卡纳／四花色筛选。每张牌只展示核心主题、正位说明与逆位说明；抽牌与来信页的已翻开牌提供“查牌义”入口，并标明本次方向。

内容参考 Tina Gong 在 Labyrinthos 发表的逐牌资料，以中文概括整理，非逐字翻译或统一标准。AI 解读直接使用手册中实际抽中方向的说明、关键词、来源与版本，牌灵只能影响视角和表达。详见 [牌义资料与核对说明](docs/MEANINGS.md)。

## 启动

安装 Node.js 22.16 或更高版本（建议使用 24），在本目录执行：

```sh
npm ci
npm start
```

在浏览器打开 http://127.0.0.1:3000 。首次启动前先用 `npm ci` 安装依赖。端口可通过 `PORT=3001 npm start` 修改。服务仅监听本机；手机可使用桌面浏览器的移动设备预览，本机手机访问需要自行配置安全的本地转发，默认不向局域网公开。

使用期间保持启动服务的进程运行。关闭服务后，浏览器可能仍显示已打开的书页，但新的图片加载与模型请求无法继续；重新运行 `npm start` 即可恢复。牌面图片允许浏览器缓存，方便重复翻阅；页面代码与模型响应不缓存。

填写兼容 OpenAI Chat Completions 的 API 地址（例如 `https://api.openai.com/v1`）、自己的 API Key 和服务商提供的模型名。也可填写完整 `/chat/completions` 地址。地址原样保留自定义路径，不会自动补 `/v1`。服务负责转发，避免浏览器跨域限制。支持 HTTP 本地模型服务和 HTTPS 远程服务，不跟随重定向。无内置付费密钥、无模拟成功回答。

界面以书页组织，顶部可切换“写下心事、抽牌仪式、牌间来信、往日手札”。长解读与历史记录分页展示，不再向下堆叠所有模块。右上角“模型连接”打开设置弹窗，保存后自动恢复地址与模型；若希望刷新后直接使用，请主动勾选记住密钥。

首次点击“建立我的牌灵”，洗开 22 张大阿卡纳并手选一张，查看性格后为这副牌命名。牌序在选牌前保存，刷新后可继续；选定后不提供重抽。每个浏览器保存一副私人牌的档案，后续可修改名字。牌灵影响观察角度、表达与追问，不影响正式抽牌的 78 张牌、正逆位或基本牌义。新手札绑定当时档案；旧手札不补绑，继续使用默认风格。档案只展示牌灵的性格、关注角度与示例追问；资料依据保留在内部配置与模型上下文中。详见 [牌灵设计](docs/SPIRIT.md)。

再写问题并选择牌阵，默念后洗牌，拖动滑块切牌，再横向浏览牌背、选牌并逐张翻开。全部翻开后手动开始解读。追问时可先输入问题再补抽一张，补牌后点击解读；每次手札仅限一次。另起一篇不会删除旧记录。

API Key 默认只在当前页面内存中使用；主动勾选记住后才保存到当前浏览器，取消立即移除保存的密钥。历史与密钥分开保存。生成时问题、牌面、牌义、牌灵性格和对话发送至你指定的模型服务。请只连接可信服务。历史仅存在当前浏览器，清除站点数据即丢失。

## 邀请码上线体验版

现在支持两种运行模式：默认本地模式继续使用自己的模型连接；`TAROT_MODE=hosted` 由服务端统一提供模型，访客只需输入邀请码。服务端密钥不会发送给浏览器。

邀请码默认每日 5 次、累计 20 次；全站每日 100 次、累计 1000 次。额度持久化保存，刷新、退出或重启不重置。每次生成与重试计一次；抽牌、翻页和历史查看不计。所有数值可调整。

推荐使用 Vercel Hobby + Neon PostgreSQL：页面与接口同域部署，额度、限流和并发名额由数据库统一保存。仓库已提供函数入口、部署配置、数据库初始化迁移、环境变量示例、邀请码生成工具及部署检查命令；也保留 Render 单实例文件存储方案。实际云服务尚未创建；完整步骤与用量规则见 [上线部署说明](docs/DEPLOY.md)。

# 月下手札 · 塔罗

本地运行的 78 张经典韦特塔罗与 AI 解读工具。支持三种牌阵、实际洗切牌、手动选牌与翻牌、连续追问、一次补牌、本地历史和中断恢复。

## 启动

安装 Node.js 22.16 或更高版本（建议使用 24），在本目录执行：

```sh
npm start
```

在浏览器打开 http://127.0.0.1:3000 。无需安装运行依赖。端口可通过 `PORT=3001 npm start` 修改。服务仅监听本机；手机可使用桌面浏览器的移动设备预览，本机手机访问需要自行配置安全的本地转发，默认不向局域网公开。

使用期间保持启动服务的进程运行。关闭服务后，浏览器可能仍显示已打开的书页，但新的图片加载与模型请求无法继续；重新运行 `npm start` 即可恢复。牌面图片允许浏览器缓存，方便重复翻阅；页面代码与模型响应不缓存。

填写兼容 OpenAI Chat Completions 的 API 地址（例如 `https://api.openai.com/v1`）、自己的 API Key 和服务商提供的模型名。也可填写完整 `/chat/completions` 地址。地址原样保留自定义路径，不会自动补 `/v1`。服务负责转发，避免浏览器跨域限制。支持 HTTP 本地模型服务和 HTTPS 远程服务，不跟随重定向。无内置付费密钥、无模拟成功回答。

界面以书页组织，顶部可切换“写下心事、抽牌仪式、牌间来信、往日手札”。长解读与历史记录分页展示，不再向下堆叠所有模块。右上角“模型连接”打开设置弹窗，保存后自动恢复地址与模型；若希望刷新后直接使用，请主动勾选记住密钥。

先写问题并选择牌阵，默念后洗牌，拖动滑块切牌，再横向浏览牌背、选牌并逐张翻开。全部翻开后手动开始解读。追问时可先输入问题再补抽一张，补牌后点击解读；每次手札仅限一次。另起一篇不会删除旧记录。

API Key 默认只在当前页面内存中使用；主动勾选记住后才保存到当前浏览器，取消立即移除保存的密钥。历史与密钥分开保存。生成时问题、牌面、牌义和对话发送至你指定的模型服务。请只连接可信服务。历史仅存在当前浏览器，清除站点数据即丢失。

## 邀请码上线体验版

现在支持两种运行模式：默认本地模式继续使用自己的模型连接；`TAROT_MODE=hosted` 由服务端统一提供模型，访客只需输入邀请码。服务端密钥不会发送给浏览器。

邀请码默认每日 5 次、累计 20 次；全站每日 100 次、累计 1000 次。额度持久化保存，刷新、退出或重启不重置。每次生成与重试计一次；抽牌、翻页和历史查看不计。所有数值可调整。

仓库已提供 Render 单实例部署配置、持久化磁盘设置、环境变量示例、邀请码生成工具及部署检查命令。实际云服务尚未创建；完整步骤与用量规则见 [上线部署说明](docs/DEPLOY.md)。

## 测试

```sh
npm test
```

全部仓库测试均由 Node 内置测试运行器执行，无需额外依赖。模型转发测试使用本地模拟的兼容服务，不调用付费模型。本次已用用户配置的真实服务跑通首轮、追问与补牌；具体结果与验证边界见 [验收记录](docs/ACCEPTANCE.md)。真实服务的内容质量仍依赖所选模型。

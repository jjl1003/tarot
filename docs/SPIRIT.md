# 牌灵：一副私人牌的相处方式

本次在现有抽牌与解读流程上增加一副保存在当前浏览器的私人牌。牌灵是产品的仪式与性格设定，不宣称统一的传统规则或更准确的预测。本版不提供多副牌管理、重抽、跨设备同步或线上抽牌的密码学验证。

## 建立与使用

首次开始新手札前，通过首页“建立我的牌灵”进入仪式。程序使用浏览器安全随机源洗开 22 张大阿卡纳，在手选之前保存顺序；用户点击某个牌背，该位置决定牌灵，立即保存后展示结果。关闭或刷新可继续未完成的选择，已翻开的牌不可重抽。抽取无需模型调用，不消耗体验额度。

档案包含随机 ID、建立日期、名字、牌灵 ID 和本次 22 张牌顺序。用户可为牌命名或改名，名字限制 1 至 40 字。存储失败时显示错误，不展示未保存的新抽取结果。

每篇新手札保存档案快照。改名不会改变旧手札，旧版记录没有牌灵时不追溯绑定。追问、补牌与失败重试都使用该篇快照。正式抽牌继续使用全部 78 张牌，牌灵牌也在其中；牌灵选择与正式牌阵完全独立。

## 22 种性格

`public/spirit.js` 为每张大阿卡纳定义表达风格、关注角度与示例追问。例如恶魔关注欲望、依赖和交换代价，直接但不羞辱；月亮关注感受、投射与未知信息，细腻且保留判断；皇帝关注责任、边界和持续安排，稳重明确。

解读时根据牌灵 ID 读取内置性格，避免从浏览器存储加载任意提示词。用户起的名字不传给模型。模型先回应问题核心，再说明牌面与牌位依据；性格可影响观察与追问，不能改牌、扭曲基本牌义、编造背景、断言他人内心或保证预测。示例追问不是固定台词，应结合当前问题调整。

本地与邀请码模式都传递相同的牌灵背景。邀请码服务仍覆盖客户端系统消息，使用服务端固定解读规则，并保留用户消息中的牌灵信息。

## 资料依据与产品转译

22 种牌灵均有内部资料依据：

- **现代牌灵实践参考：**林詣晉在 [017 Cafe 的牌灵解析](https://017cafe.com/main_card/)，用简短主题标签标明对应章节，不转载正文，也不把作者的个人实践写成全行业定论。
- **基础牌义参考：**每张大阿卡纳分别关联 Tina Gong 的 Labyrinthos 逐牌资料，与手册的来源一致。基础牌义并不直接规定牌灵怎样说话。
- **本站转译：**为每张牌说明怎样从主题转换为关注角度、语气和追问。语气及示例问题仍是产品设计，并非原作者原话。

牌灵档案只展示最终性格、关注角度与示例追问，不展示资料依据入口、章节、来源链接或本站转译说明。来源元数据、对应章节、转译理由和核对日期仍保留在内部配置与模型上下文中，不采用浏览器档案中的任意来源字段。

模型上下文同步携带以上分层和来源，系统规则禁止冒称公认定论、原作者原话，或把牌义资料说成直接规定语气的牌灵文献。引用只支持资料可追溯，不证明预测有效或风格演出稳定。本版参考版本为 2026-11-07.1，提示词版本为 4；原有牌灵 ID、名字与 22 份风格配置保持不变，补充依据不重新抽牌。

## 数据与验证边界

牌灵保存在 `tarot.spirit.v1`，与连接密钥、手札记录分开。清除站点数据会丢失档案。档案校验拒绝非法牌、重复／缺失顺序、损坏日期和空名字。解读时牌灵性格随问题和牌面发送到模型服务，私人牌的名字不发送。

新增测试覆盖所有性格、手选位置、刷新恢复、命名、禁止重抽、存储失败、会话快照、旧记录兼容、78 张完整性、追问与补牌、邀请码模式转发。自动测试使用模拟模型，验证上下文与转发，不证明真实模型的人设遵循率或解读质量；这些还需要用相同牌面和不同背景人工比较。

# 手动与摄像头抽牌仪式

本轮按用户提供的 [Quin 应用](https://play.google.com/store/apps/details?id=ai.askquin&hl=zh)及描述的绕动、点击切牌和顺滑选牌动作设计，沿用本站纸张与柔和绿视觉。没有使用 Quin 的代码、图片或私有资源。

## 鼠标、触屏与键盘

按住牌桌绕动，顺时针和逆时针均可。78 张牌随手散开并在松手时收拢。连续绕动每约四分之一圈的一半触发一次实际分组交错，方向影响先合入哪一叠，分组大小由 Web Crypto 随机数决定。中心抖动或横跨牌桌的跳跃不算洗牌。键盘左右方向键也可完成同样的牌序操作。

每次有效洗动保存 `mixing` 阶段、完整牌序和次数；松手、取消指针或刷新不会额外重排。点击“洗好了”只进入切牌，不再次随机。此前已在切牌或后续阶段的旧手札继续可用。

切牌时上下移动到某个位置，再点击牌堆。分成两叠的预览保存在 `cutPreview`，此时不改变牌序；确认后才将下叠移到上叠之前。两端至少各保留一张。键盘可用方向键、Home/End 和回车。选牌动画先保存真实选择，再显示落位过程，重复点击在动画结束前被拦截；刷新恢复已选牌，不额外抽牌。减少动画偏好下直接落位。

## 可选摄像头模式

- 主动点击开启后，先准备模型，再申请摄像头。仅 HTTPS 或 localhost 且支持 Worker、WASM、ImageBitmap 和摄像头 API 的浏览器可用。
- 仅申请视频，`audio:false`；不录制，也不将视频、图片或手部坐标写入历史或发给服务器。视频帧通过可转移的 ImageBitmap 交给本机 Worker，处理完即关闭。
- MediaPipe Tasks Vision 固定为 0.10.32，JavaScript 与 WASM 加载器随网站提供；WASM 二进制从 jsDelivr 的对应固定版本路径下载，Hand Landmarker 模型从 Google 官方模型地址下载。资源请求会像普通联网下载一样暴露请求 IP；摄像头画面不随这些请求上传。首次加载可能较慢，网络失败可退回手动模式。
- 同时跟踪最多两只手，约每秒 10 帧，图像识别不阻塞页面动画。洗牌只需一只张开的手掌，也支持双手，使用手掌中心，不使用食指画圆或两指捏合来代替洗牌。
- 初次开启让张开的手掌自然停留约 600ms。单手以镜头画面中心为旋转中心，双手以初始掌心中点定位。定位期间不改变牌序。之后顺时针或逆时针绕动手掌，像鼠标一样搅动同一桌散牌，不按两掌距离把牌分成两堆。鼠标与摄像头共用同一散牌渲染函数和角度判定，每段约 45 度的有效绕动改变并保存一次牌序；两个手掌共用一个累计器，避免同一动作重复计次。单纯拉开、靠拢、保持姿势都不计次。
- 自然停住约 350ms 后暂停；收掌、捏合、没有有效手掌或超出画面时也暂停并收拢。一只手就能继续操作；有效手掌数量变化时清空未完成角度，避免误计次。重新出现时不沿用失去跟踪前未完成的角度。检测结果数组调换顺序时，按位置连续性匹配两个手掌，避免错误跳转。
- 识别面板实时叠加两组 21 点骨架和掌间连线，显示入镜状态、定位进度、本轮绕动进度及方向。百分比表示距离下一次洗牌的绕动进度或两指开合程度，不是模型置信度或识别准确率。成功记录洗牌会显示对应次数。面板固定在仪式右页右上角，显示小幅摄像头画面及当前状态，不占用左页滚动区域；手机尺寸下缩小显示。
- 切牌和选牌使用单手光点与拇指食指捏合。光点镜像映射并做平滑处理，指尖距离按掌宽归一化，以不同阈值识别捏合和松开。需要时点击“重新校准”记录两指捏合与张开范围。切牌或按钮需要先在目标上停留至少 280ms，再捏合并松开，每次切牌立即交换当前牌堆两段，保存次数并继续留在切牌阶段；长时间捏住不会重复触发，松开后可再次捏合。点击“切好了”才进入选牌，完成动作不额外改变牌序；抽牌还需捏住后向上拉出至少 26px 再松开。仅捏合、快速路过、手丢失跟踪都不能确认抽牌。
- 手离开画面取消未完成动作，重新出现后需要先张开手。关闭、离开仪式、打开弹窗、切入后台、摄像头断开或识别故障都会释放流与 Worker。等待权限时取消，即使稍后才获得授权，也立即停止迟到的流。

识别依赖光线、遮挡、摄像头角度和手的大小，鼠标、触屏和键盘始终保留。请由同一个人操作；多人入镜时不保证跟踪同一人。当前为二维掌心轨迹驱动的洗牌交互，不进行完整的三维手掌与卡牌刚体仿真。

第三方来源与许可证见 [NOTICE](../public/vendor/NOTICE.txt) 和 [Apache License](../public/vendor/LICENSE)。API 用法依据 [Google Hand Landmarker 文档](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。CSP 仅新增本机 Worker、WASM 编译和固定模型资源路径，未开放任意脚本或 JavaScript eval。

## 验证边界

自动化测试使用确定的牌序、虚构手部坐标、模拟视频和 Worker，验证方向、数据完整性、刷新恢复、抬起后松开选牌、丢失跟踪取消、权限拒绝与迟到授权资源释放。独立浏览器检查已使用真实 MediaPipe Worker/WASM/模型完成初始化，然后模拟拒绝摄像头权限，未开启用户真实摄像头。

浏览器实测完成鼠标绕动、键盘双向洗牌、点击切牌预览和选牌落位，不调用付费模型。尚未进行真实摄像头下不同光线、肤色、设备和多人环境的硬件验收，不能将模拟坐标测试当作识别准确率或硬件兼容性保证。

测试覆盖自然停留定位、单手及双手双向绕动、拉开靠拢不计次、维持姿势不连发、全部手掌丢失或收掌暂停、检测数组顺序颠倒、骨点与连线绘制、进度语义，控制器实际计次、重复捏合切牌及重新挂载后重新张开才可继续切牌。还比较了同样输入下鼠标与摄像头的全部 78 张牌变换，验证两者使用同一散牌布局。本地浏览器演示明确标注“模拟坐标 · 非摄像头”，不作为真实摄像头识别准确率证明。
